# ⚡ AlphaPulse · 美股標普 500 量化動能終端 (QUANT PRO)

自動化美股標普 500 多因子動能篩選、歐奈爾機構籌碼評級与五重硬核買點推薦系統。

## 核心功能

1. **多因子綜合動能排榜 (`screener.py`)**：
   - 整合當日爆發力 (`pulse`)、均線乖離 (`D20 / D50 / D200` 帶封頂保護)、歐奈爾機構吸籌評級 (`IBD Acc/Dist A~E` 結合日內收市位置 CLV)、位階 (`ZONE`)、量比 (`vol_ratio`)、同板塊相對強度 (`sector_pct`) 及過熱扣分機制。
2. **🔥 今日核心推薦 TOP 5（五重國際量化漏斗）**：
   - **大市風控閘**：自動檢測 `SPY` 對比 `200MA` 與 `20MA` 狀態（開 / 半倉 / 關）。
   - **Minervini 52 週強者恆強準則**：距離 52 週高位 30% 以內、遠離 52 週低位，排除破底死貓彈。
   - **歐奈爾口袋支點 (Pocket Pivot)**：當日收升 ≥ 0.5%、量比 ≥ 1.05x 且成交量超越過去 10 日最大陰燭量。
   - **賣壓極致枯竭 (Volume Dry-Up, VDU)**：回踩 20MA 附近時量比 ≤ 0.65x，浮額鎖定。
   - **不對稱盈虧比 (R:R ≥ 1.8)**：每張推薦卡直接標示 **🎯 建議買入區間 (`$Support ～ $Spot`)**、嚴格止蝕位與目標阻力位。
3. **手機與電腦雙視圖終端 (`index.html`)**：
   - 支援「📱 手機卡片流」與「📊 電腦寬表格」一鍵切換、TradingView 互動圖表、四維量化圖表診斷、$10萬帳戶 0.5% 風險倉位試算器、以及一鍵呼起富途牛牛 App。
4. **GitHub Actions 全自動日更 (`.github/workflows/update.yml`)**：
   - 逢美股交易日收市後（香港時間清晨 `05:25 HKT`）自動抓取最新行情並更新 `screener_data.json`。
